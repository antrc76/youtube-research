# Example profile

This file is entirely optional. If present at `PROFILE_PATH` (default:
`profile.md` in the repo root), the "Analyse for me" panel includes it in
the prompt so the model's take is weighted against your actual interests
instead of giving a generic opinion. If it's missing, the feature still
works — it just gives a general assessment instead of a personalised one.

Copy this file to `profile.md` and edit it; `profile.md` is gitignored so
your real one never gets committed.
